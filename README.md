# MIT 8103 — Advanced Database Systems Portfolio

## Project Overview
This repository contains my coursework for MIT 8103 — Advanced Database Systems. The project uses a University Student Result Management System as its case study to explore relational database design, query processing and optimisation, transaction management, NoSQL data modelling, and distributed/cloud databases.

## Case Study
The University Student Result Management System is designed to organise student, course, registration, and academic result information. It provides a practical context for examining database structures, integrity constraints, query performance, transaction safety, and cloud data storage.

## Portfolio Structure

### Portfolio 1: Database Design and Modelling
Database requirements, entity-relationship modelling, relational schema, keys, constraints, and normalisation.

### Portfolio 2: Query Processing and Optimisation
SQL queries, query results, execution plans, indexing and optimisation evidence, and performance analysis.

### Portfolio 3: Transactions and Concurrency
Transaction operations, COMMIT and ROLLBACK, isolation, concurrency challenges, and control mechanisms.

### Portfolio 4: NoSQL and Advanced Data Models
NoSQL data modelling, sample documents and queries, implementation evidence, and suitability analysis.

### Portfolio 5: Distributed and Cloud Database Exercise
MongoDB Atlas cloud deployment, database documents, monitoring evidence, and discussion of distribution, replication, availability, and consistency.
